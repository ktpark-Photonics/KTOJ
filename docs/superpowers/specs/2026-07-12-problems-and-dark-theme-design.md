## A. 추가 문제 10개

모두 순수 stdin→stdout. 각 문제 폴더 `problems/<slug>/`: `problem.md`(front-matter: title/difficulty/time_limit_ms=1000/memory_limit_mb=128 + 지문) + `tests/1.in`,`1.out`(샘플), `tests/2.in`,`2.out`(채점용). `seed.py`가 slug 기준 upsert.

각 문제의 정확한 입출력(채점 ground truth):

### 왕초보
1. **subtract-two** — 두 수의 차. 입력 `A B` → 출력 `A-B`.
   - t1: `5 3` → `2` | t2: `0 10` → `-10`
2. **multiply-two** — 두 수의 곱. 입력 `A B` → `A*B`.
   - t1: `3 4` → `12` | t2: `-2 5` → `-10`
3. **four-operations** — 사칙연산. 입력 `A B`(B≠0) → 5줄: `A+B`, `A-B`, `A*B`, `A//B`(몫), `A%B`(나머지).
   - t1: `7 3` → `10\n4\n21\n2\n1` | t2: `10 5` → `15\n5\n50\n2\n0`
4. **even-or-odd** — 짝/홀. 입력 `N` → `even` 또는 `odd`.
   - t1: `4` → `even` | t2: `7` → `odd`
5. **absolute-value** — 절댓값. 입력 `N` → `|N|`.
   - t1: `-5` → `5` | t2: `3` → `3`

### 초보
6. **sum-even-to-n** — 1~N 중 짝수의 합. 입력 `N` → 합.
   - t1: `10` → `30` (2+4+6+8+10) | t2: `1` → `0`
7. **factorial** — 팩토리얼. 입력 `N`(0≤N≤20) → `N!`.
   - t1: `5` → `120` | t2: `0` → `1`
8. **gcd-two** — 최대공약수. 입력 `A B`(양의 정수) → gcd.
   - t1: `12 18` → `6` | t2: `7 5` → `1`
9. **digit-sum** — 자릿수의 합. 입력 `N`(음이 아닌 정수) → 각 자리 숫자 합.
   - t1: `12345` → `15` | t2: `0` → `0`
10. **stars-triangle** — 별 찍기. 입력 `N` → i번째 줄(1..N)에 `*` i개, 왼쪽 정렬.
    - t1: `3` → `*\n**\n***` | t2: `1` → `*`

> 참고: grader가 각 줄 오른쪽 공백/끝 빈 줄을 정규화하므로 마지막 개행 유무는 무관. 내용만 정확하면 됨.

## B. 모던 다크 코더 테마

로직/라우트/판정 불변. `app/web/templates/base.html`의 인라인 CSS를 전면 교체하고, 템플릿 마크업을 소폭 조정(네비바, 난이도 배지 클래스, 판정 배지).

### 디자인 시스템
- **색상 토큰**
  - 배경 `--bg: #0d1117`, 표면/카드 `--surface: #161b22`, 경계 `--border: #30363d`
  - 본문 글자 `--fg: #c9d1d9`, 흐린 글자 `--muted: #8b949e`
  - 강조(시안) `--accent: #58d6d0`, 링크 `--link: #58a6ff`
  - 판정: 성공 `--ok: #3fb950`, 실패 `--bad: #f85149`, 대기 `--pending: #d29922`
  - 난이도 배지: 왕초보 `#3fb950`(연두 계열), 초보 `#58d6d0`(시안 계열)
- **타이포**
  - 모노스페이스 스택(헤더/네비/로고/판정/코드/배지): `ui-monospace, SFMono-Regular, "Consolas", "D2Coding", monospace`
  - 본문 지문: `system-ui, "Segoe UI", sans-serif`
  - `body` 최대폭 900px, 중앙 정렬, 여유 있는 라인하이트

### 컴포넌트
- **상단 네비바:** 어두운 바, 좌측 `▓ KTOJ`(로고, 홈 링크, 모노스페이스), 우측 `문제` 링크. sticky 아님(단순).
- **문제 목록:** 다크 표(`--surface` 배경, `--border` 구분선), 행 hover 시 살짝 밝아짐, 제목은 링크색, 난이도는 색 구분 배지.
- **문제 상세:** 지문 카드, 배지 줄(난이도/시간/메모리), 예제 입출력은 터미널풍 `pre`(어두운 배경+모노), 제출 폼 textarea 다크+모노, 제출 버튼은 강조색 배경.
- **제출 결과:** 큰 판정 텍스트(AC=`--ok` 초록 / 그 외=`--bad` 빨강), 실행시간·틀린 케이스·메시지, 제출 코드 블록. HTMX 폴링 마크업/동작 그대로.

### 접근성/견고성
- 색만으로 정보 전달하지 않도록 판정은 텍스트 라벨(AC/WA…) 유지.
- 기존 웹 테스트가 검사하는 문자열(제목/지문/상태 텍스트)은 그대로 노출되어야 함.
